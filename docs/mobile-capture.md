# Mobile Capture

## Workflow
- Use a dedicated `capture.md` page for quick entries.
- Avoid heavy re-indexing on mobile if possible.
- Ensure Syncthing has finished syncing before opening Logseq on mobile.

## App Integration
- Use "Share to Logseq" features carefully.
- Preferred method: Append text to a specific journal file via a text editor if Logseq is slow to load.
