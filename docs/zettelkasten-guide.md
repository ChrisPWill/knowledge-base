# Zettelkasten Guide

## Note Types
- **Literature Notes**: Raw notes taken while consuming content. Reference the source.
- **Permanent Notes**: Atomic, self-contained ideas written in your own words.
- **Structure Notes (MOCs)**: Maps of Content that link related permanent notes.

## Naming Conventions
- Use descriptive titles.
- Use tags for broad categories.
- Use page-linking for direct relationships.

## Tagging
- #lit for literature notes.
- #permanent for verified ideas.
- #todo for actionable items.
